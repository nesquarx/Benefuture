Reality is the part of the universe that one can perceive or change. It is the pattern of energy and matter that one can [[interact]] with.

==Aspects==
===Real===
If a [[thing]] is claimed to exist in reality, it is to claim that the pattern of the thing is a subset of the pattern of reality. If [[proof|proven]] [[true]] with the same means that we perceive reality with, that thing can be called real.

===Simulation===
* When a [[thing]] only exists as a pattern represented symbolically through a substrate pattern in reality, it is a simulation.
* A simulated thing is real inside the scope of the simulation, but unless it interacts with reality outside its substrate, it is not a part of reality. When it can interact with reality, it should be treated the same as a real thing that can interact the same way.


==Examples==
* Rocks described in books, if such rocks can be found in reality, then it is the description of a real rock, if not, they are simulated only in the book.
* A [[being]] described inside a static simulation like a book, is a description and not a real being because it is not active and can not interact with reality. If the described being exists in reality, the being in reality is a real thing while the description still remains the description.
* A [[person]] who exists in an active simulation, which can interact with reality in the same way a person can, is real. If the person can only interact with other parts of the simulation, they are considered real inside the simulation and treated as a real person inside the simulation, but are still not considered a real person out in reality.
* If the known universe turns out to be a simulation, for all the beings inside the simulation, it is the real universe and notions of reality apply.
