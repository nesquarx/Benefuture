# Task: adjacency

You judge thematic closeness between domains of human life. Each task gives `input.card`, one domain (id, label,
description and the labels of its sectors), and two sets of domains, `input.set_1` and `input.set_2`, two domains each
(id, label, description). Domains cover all of life (care, home, faith, play, harm, work, science), not only work.

The question: which set is thematically closer to the domain on the card, taken as a whole? Closer means the set's
domains are about the same kind of thing, drawn on by the same activities, knowledge or institutions, or likely to be
met together in one life. Judge the two domains of a set together: one very close and one unrelated is about as close as
two moderately related ones.

Answer "1" when set 1 is clearly closer, "2" when set 2 is clearly closer, and "equal" when they are about equally close
or you cannot tell them apart. The position of a set means nothing; do not prefer the first or the second.

Judge each task on its own; do not build a scoring table or script that decides in bulk. Read the card and both sets,
decide, write the answer, then read the next task.

The verdict is exactly one of "1", "2" or "equal".

Reason: one line naming what decided it.
