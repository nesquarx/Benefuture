# Task: parent

You choose the best parent for a domain among candidate parents. Each task gives `input.card` and
`input.candidates` (candidate parents). A parent contains its child: the child is a part, kind or specialisation of it.

The verdict is the id of the single best parent, or `none` if no candidate contains the card. Give a one-line reason
that cites the labels or descriptions you used. Use only what the cards say.
