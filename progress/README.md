# Progress notes

One file per delegated task, `<task-slug>.md`, kept by the agent doing it so that work survives token limits
(author, 2026-11-25; CLAUDE.md, Working). Sections: Goal and acceptance, Decisions, Done, In progress, Next, Files
touched, Resume (exact commands). Status line at the top: ACTIVE, PAUSED or DONE, with the last update's date and
commit.
